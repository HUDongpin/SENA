建模流程 Pipeline
1. 上传与校验

导入互动日志、讨论文本、编码结果与 codebook。系统检查 ID 是否一致、时间戳是否可排序、code 是否在 codebook 中。

CSVJSONLxAPI
2. 构造 SNA 层 S

按回复、共现、协作、提及或同组事件聚合 person–person 边。可选择 directed/undirected 与 time-sliced。

3. 构造 ENA 层 W

按 stanza / moving window / conversational turn 计算 code–code 共现，形成每个 unit 的 ENA connection vector。

4. 构造桥接层 B

统计每个 learner 对每个 code 的贡献，也可扩展为 person–code-pair 贡献，用于解释“谁推动了哪些概念连接”。

5. 融合布局

支持三种模式：解释型布局、ENA unit space 叠加 SNA 边、基于 Afusion 的 joint embedding。
